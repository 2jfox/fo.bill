**ПОРІВНЯЛЬНА ТАБЛИЦЯ**<br>
**до проєкту Закону України «Про забезпечення державної монополії у сфері обігу лікарських засобів, реформування фармацевтичної галузі та оптимізацію логістичної інфраструктури»**

Запропоновані в цій таблиці зміни включено до розділу V проєкту Закону. Наведені у вихідному файлі чинні редакції та реквізити законів не перевірялися за офіційними джерелами.

| **ЦИВІЛЬНИЙ КОДЕКС УКРАЇНИ** | | |
| **Стаття 325. Суб’єкти права приватної власності** <br>1. Суб’єктами права приватної власності є фізичні та юридичні особи. <br>2. Фізичні та юридичні особи можуть бути власниками будь-якого майна, за винятком окремих видів майна, які відповідно до закону не можуть їм належати. | Статтю 325 доповнено частиною третьою такого змісту: «3. У приватній власності не можуть перебувати підприємства з виробництва лікарських засобів, суб’єкти оптової та роздрібної торгівлі лікарськими засобами, а також стратегічні логістичні оператори, визначені законом про державну монополію у сфері обігу лікарських засобів». | Запропоновано обмежити приватну власність на визначені підприємства й операторів. Необхідно визначити їх перелік, правовий режим майна та перехідний механізм. |
| **ЗАКОН УКРАЇНИ «ПРО ЛІКАРСЬКІ ЗАСОБИ»** | | |
| **Стаття 10. Умови виробництва лікарських засобів** <br>За редакцією, наведеною у вихідній таблиці: виробництво здійснюється фізичними або юридичними особами на підставі ліцензії, виданої в установленому законодавством порядку. | Статтю 10 викладено в редакції: «Виробництво лікарських засобів здійснюється виключно державними підприємствами, що входять до складу Фармацевтичного науково-виробничого кластера, на підставі ліцензії та відповідно до державного замовлення». | Запропоновано монополізувати виробництво лікарських засобів за державними підприємствами кластера; чинну редакцію та регуляторні наслідки слід перевірити. |
| **Стаття 19. Порядок торгівлі лікарськими засобами** <br>За редакцією, наведеною у вихідній таблиці: оптова й роздрібна торгівля здійснюється підприємствами, установами, організаціями та фізичними особами — підприємцями на підставі ліцензії. | Статтю 19 викладено в редакції: «Виключне право на здійснення оптової та роздрібної торгівлі лікарськими засобами та медичними виробами на території України належить Єдиній державній фармацевтичній корпорації. Роздрібна реалізація здійснюється через державну аптечну мережу за єдиними фіксованими цінами, затвердженими у Державному фармацевтичному реєстрі». | Запропоновано виключне право державної корпорації на торгівлю ліками та медичними виробами; поправка потребує узгодження з ліцензуванням, конкуренцією та безперервністю постачання. |
| **ЗАКОН УКРАЇНИ «ПРО ПУБЛІЧНІ ЗАКУПІВЛІ»** | | |
| **Стаття 3. Сфера застосування Закону** <br>У вихідній таблиці зазначено, що частина п’ята містить перелік винятків (пункти 1–23), а пункт 24 відсутній. Актуальну редакцію необхідно звірити. | Частину п’яту доповнено пунктом 24 такого змісту: «лікарські засоби та медичні вироби, що замовляються закладами охорони здоров’я державної та комунальної форм власності безпосередньо у Єдиної державної фармацевтичної корпорації або державних підприємств Фармацевтичного науково-виробничого кластера». | Запропоновано виняток із процедур публічних закупівель для закупівель через державну корпорацію або підприємства кластера; слід оцінити відповідність законодавству про закупівлі та міжнародним зобов’язанням. |
| **ЗАКОН УКРАЇНИ «ПРО ЦІНИ І ЦІНОУТВОРЕННЯ»** | | |
| **Стаття 12. Державні регульовані ціни** <br>У вихідній таблиці наведено частину першу про запровадження регульованих цін на соціально значущі товари та товари суб’єктів із монопольним становищем. Чинний текст потребує звірення. | Частину першу доповнено абзацом такого змісту: «На всі лікарські засоби та медичні вироби, включені до Державного фармацевтичного реєстру, встановлюються єдині державні фіксовані оптові та роздрібні ціни». | Запропоновано закріпити єдині фіксовані оптові й роздрібні ціни; необхідно визначити методику ціноутворення, перегляду цін та контролю. |
