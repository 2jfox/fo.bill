# Законопроєкт щодо посилення відповідальності за порушення правил додержання тиші

Цей пакет документів містить офіційну законодавчу ініціативу, спрямовану на захист населення від шкідливого впливу шуму та забезпечення громадського порядку в житлових будинках і населених пунктах України.

## 📋 Склад пакета документів:

1. **[Проєкт Закону України](Проєкт_Закону.md)** — пропонує внесення змін до **статті 182 Кодексу України про адміністративні правопорушення (КУоАП)** з метою збільшення штрафів за порушення тиші в середньому в 10 разів (до 850–1700 грн для громадян за перше порушення).
2. **[Пояснювальна записка](Пояснювальна_записка.md)** — містить детальне обґрунтування необхідності прийняття акта, аналіз його фінансово-економічного впливу та прогноз соціально-економічних наслідків.
3. **[Проєкт Постанови Верховної Ради України](Проєкт_Постанови_ВРУ.md)** — нормативний документ для реєстрації законопроєкту та його прийняття за основу у першому читанні.
4. **[Порівняльна таблиця](Порівняльна_таблиця.md)** — наочне зіставлення чинної редакції статті 182 КУоАП із запропонованими змінами та новими розмірами санкцій.

## 🎯 Основна мета:
Повернення адміністративним штрафам їхньої превентивної (попереджувальної) функції, яка була втрачена через інфляцію, та захист конституційного права громадян на відпочинок і безпечне для життя та здоров'я довкілля.
